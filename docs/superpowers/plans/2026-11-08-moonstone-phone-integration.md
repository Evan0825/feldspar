# 月石单样机手机联调计划

目标是用同一台 ESP32-S3 完成候选固件启动、微信真机手动控制和停止回读，再单独验收云端与自检。依据 [README 验收表](../../../README.md) 和 [现装样机记录](../../../validation/20261107-hardware-bringup/README.md)。

## 1. 备份与候选固件

- 通过 USB 核对板卡身份和 Flash 容量。备份完整内置 Flash，核对板上摘要、活动槽和原固件指纹。备份留在本机私有目录，其中包含配网数据。
- 编译 ESP32-S3 观测版。该样机 GPIO7 使用按下为高电平的板卡配置。保留原配网分区和原应用槽，首启保护现有 NVS 和外置音效文件。
- 先校验写入的候选应用，再切换启动槽。启动后核对版本、蓝牙状态回读、音效数量与默认停止状态。

## 2. 手机验收

打开真实测试后端的微信预览，先完成下表。自检入口在「设备详情」，可最后再做。测试时把样机和振动片平放在桌面，从低音量和低亮度开始。

| 顺序 | 手机上怎么测 | 记录什么 |
| --- | --- | --- |
| 1 | 打开首页并进入「设备详情」 | 手机蓝牙是否连接，设备 Wi-Fi 是否显示当前网络和 IP |
| 2 | 设备详情点「恢复手动控制」 | 是否收到恢复确认，灯、声音、振动是否保持停止 |
| 3 | 首页开夜灯，调低亮度，再关闭 | 实物亮、暗、灭与页面显示是否一致 |
| 4 | 首页低音量播放一个音效，再点停止 | 是否听见，是否完整，手动停止是否有效 |
| 5 | 低亮度开灯后，在设备详情点「停止全部输出」 | 实物熄灭，页面显示已锁定，恢复前无法重新启动 |
| 6 | 恢复后复测实体短按切灯和长按 2 秒全停 | 短按动作、长按动作、松手后状态 |

振动短测、超时和蓝牙断连的实物停止由电脑发送有限时的测试指令，手机侧核对状态。结果按「项目／页面提示／实际动作」回报。

## 3. 云端与自检

给同一台样机配置独立测试 MQTT 身份和匹配的 TLS 服务，验证设备上报与远程停止回执。麦克风就绪后，从设备详情打开自检，观察振动片实际启动并停下，再进行人工确认。自动提醒保持关闭，夜间数据与 OTA 回滚单独验收。
