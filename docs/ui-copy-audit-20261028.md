# 月石全页面文案与提醒方案核对

日期：2026-10-28。范围为本地原生演示版 21 个路由及 GitHub 集成版 19 个路由。两版沿用各自现有 AI 信息结构；本次没有迁移 AI 架构。

## 确认规则

- 助手名称为「AI」，底栏为「月石／睡眠／AI／我的」。时段含义的「今晚设置／今晚提醒」保留。
- 「提醒方案」显示固定振动、声音提醒、灯光提醒。新用户声音与灯光默认勾选，取消勾选表示不纳入方案；固定振动没有取消控件。
- 已保存的 `excludeSoundReminder`／`excludeLightReminder` 含义不变，选中态为其反值；新账号显式写入 false，兼容旧数据库仍保留 DEFAULT 1 的列。登录不覆盖旧选择。
- 勾选允许方式并不直接触发声音、灯光或振动，也不扩大硬件自动输出权限；手动助眠控制保持独立。
- 页面仅保留功能标题、数据、可操作状态、错误和必要后果。重复品牌、装饰问候、宣传段落、已关闭赘文、重复加载说明与错误 Toast 已精简。
