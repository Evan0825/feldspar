# 月石 UI 风格与交互偏好

确认日期：2026-10-28。适用于本项目后续 UI 工作。

## 视觉依据

最新确认图：[四屏设计](design/moonstone-ui-approved-20261028.png)。生成图是视觉目标，阶段进度和选中项为示例，不是实机效果证据。

## 统一风格

- 暖米白页面、纸白分组、深暖棕文字、琥珀主操作、橄榄绿在线状态；复用现有设计变量。
- 大标题可用宋体；字段、正文、按钮用清晰的系统无衬线字体。单模块只保留一个功能标题。
- 卡片平整、细边框、适度圆角，不用重阴影或嵌套卡片。真实设备图片保留主机、提醒垫和连接线。
- 首页顶部导航只出现一次「月石」，不在正文重复品牌。普通菜单使用一致的图标、字号和背景；「个性化偏好」不高亮。
- 声音和夜灯只显示功能名，颜色和克制动效表达运行状态，不加「已关闭／已开启」文字；同时保留读屏标签。夜灯使用贴近月石圆顶设备造型的图标。
- 删除装饰眉题、英文分类副标题、宣传语、价值三连、重复说明和填充段落。只保留能帮助判断或操作的实际数据、字段、状态、错误和必要后果；可选说明收进上下文帮助。

## 四个页面

### 首页

紧凑方案卡：小号「当前温和方案」；「初始方案」与「收集阶段」标签同行；真实进度；细连续进度条；整行「查看方案」。不在首页堆叠具体参数。

声音与夜灯并排；「问 AI」和「实时状态」上下排列，一项一整行。底栏保持「月石／睡眠／AI／我的」。

### 温和方案详情

采用纵向四阶段时间线：初始方案（收集7日记录）→初步方案（根据记录生成）→校准期方案（结合反馈调整）→持续迭代（随记录评估）。只突出当前阶段。

下方列当前运行方式、固定默认振动及声音／灯光排除项。保留一次必要的阶段转换说明。未知阶段或进度显示待同步；没有真实策略记录时不因累计七日直接宣称初步方案、校准或持续迭代已生效。

### 我的

设备卡下方的第一项为「个性化偏好」，与其他菜单同样式，不特别着色；继续保留设备、授权、更新、分享、隐私入口。

### 个性化偏好

- 称呼与同睡情况复用首次使用的字段，可修改并重新打开核对。
- 振动是固定默认提醒方式，以只读行显示，不提供勾选、开关或取消。
- 分组统一为「提醒方案」：振动为固定默认项；「声音提醒」「灯光提醒」对新用户默认勾选，取消勾选即不纳入方案。已有保存的排除选择按原含义回显，不能被方案或 AI 覆盖。
- 方案选择不影响用户手动播放助眠声音或控制夜灯。该规则放在上下文帮助中，不重复铺文案。
- 保存需等待服务确认；失败保留编辑内容，不能显示虚假成功或修改设备配置。

## 验证与边界

检查实际页面、交互和导航；设计图不能替代功能或硬件验收。设置待确认、设备离线、数据不足和失败时使用真实状态。界面状态与动效不能替代错误提示、读屏语义或硬件回执。

## 命名与全页面文案（追加确认）

助手统一叫「AI」，不使用产品名前缀。底栏第一项为「月石」；「今晚设置／今晚提醒」等时段含义保留。所有已声明页面逐页检查：原生导航已说明页面名时不再叠加正文品牌或相同标题；加载只保留一条状态；滑块不再附带操作常识；隐私、非医疗边界、设置后果和数据来源在相关授权或判断处保留一次。失败已在页面展示时不再重复弹同一条 Toast。
