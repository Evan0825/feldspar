# 硬件接线与物料边界

V4 工程样机的 [接线和物料参考](../hardware/v4/WIRING.md)、[结构源文件与装配资料](../hardware/v4/README.md) 随版本发布。

以下来自当前固件接口，只是预期接线；未据实物核验。料号/板次/电源/实际负载待硬件负责人确认。不要仅凭此表给未知硬件烧录或通电。

| 模块 | 源码预期 | 待补资料 |
|---|---|---|
| 主控 | ESP32-S3，8 MB Flash，Octal PSRAM | 实物型号、版次、供电 |
| 麦克风 | INMP441，I2S1 BCLK15 / WS16 / DIN17，16 kHz | 增益、安装、采样标定 |
| 振动模块 | ERM，PWM GPIO42 | 驱动料号、有效电平、电流、温升与停止延迟 |
| 灯带 | RMT GPIO8，10 灯珠 | 料号、负载、电源与最大亮度 |
| 功放/扬声器 | I2S0 BCLK21 / WS14 / DOUT13 | 料号、声压与供电 |
| 外置音效存储 | SPI CS9 / CLK10 / MOSI11 / MISO12 | 容量、文件系统与损坏恢复 |
| 按键 | GPIO7，上拉/低有效 | 机械实测、短按/长按行为 |
| 雷达/温度/电流/物理反馈 | 当前驱动未提供 | 不假设存在，不生成测量值 |

本候选提供模块级接线、物料选型和 V4 外壳装配资料。整机复现仍需核对实际模块的电气特性、装配与标定。完整 PCB、原理图和量产 BOM 的公开状态见 [V4 资料说明](../hardware/v4/README.md)。

手动马达当前具有工程时长上限，自动执行关闭。软件上限不是经验证的物理安全参数。安装、联调与实际输出验证另行组织，本包只提供不操作设备的复现路径。
