| 模块 | 源码预期 | 待补资料 |

本候选不含完整 PCB、原理图、量产 BOM 与制造说明。软件开源范围已在 README 明确；需要重建整机的人仍需自行完成电气设计、实物核验与标定。外观图片只能说明设计意图。
