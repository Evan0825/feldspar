# 月石 AI 知识库

月石 AI 负责项目问答、睡眠记录解释和温和提醒方案的辅助理解。知识问答经现有 `POST /api/v1/ai/chat` 的设备访问校验后，检索本仓库的 [知识条目](../backend/app/agent/moonstone_knowledge.json)。条目含别名、证据状态、摘要和出处。后端只将本次问题及最多四条摘要交给已配置的文本模型，再校验模型所引条目。返回的 `knowledge_sources` 是服务端资料目录中的出处，体验版可以直接看到答案末尾的来源名称。资料不足时说明无法核实，模型不可用或引用无效时返回核对过的条目。

个人记录问题继续使用原有报告入口与权限。知识问答不读取个人夜间记录，也不把聊天历史混入这条模型请求。胸痛、呼吸困难及用药问题走固定安全回答。报告解读、短音频分析与设备控制是各自独立的链路。

| 类别 | 核对来源与边界 |
| --- | --- |
| 产品、设备、UI 和联调 | 项目说明、硬件和协议、规范、公开联调记录及对应固件与小程序源码。使用版本和已验证范围描述当前能力 |
| 声学和算法 | 结构化特征合同、实时音频源码、候选方案与学习算法、纯声音评级评审稿。草案和算法实现分开标记 |
| 模型训练 | v3.1、v4 训练报告、v5 流水线、模型卡、酣眠训练 HTML 报告。离线分区指标和跨来源评估并列，部署以目标固件实测为准 |
| 参考文献 | 评级评审稿所引的 Vena 等鼾声响度研究、乐鑫 AEC 文档和 scikit-learn 概率标定文档。另用 AASM 指南、NHLBI 科普及 TensorFlow Lite Micro 文档核对临床与部署边界 |

更新时只加入面向产品用户的可核对摘要，并记录对应来源、版本及验证范围。历史材料保留其证据状态。内部报告只列来源名称，公开资料可附链接。录音、训练样本、权重、用户记录、凭据、台架标识和私有部署地址不进入问答资料。条目与后端一起发布，无需向模型平台导入文档。

验证入口为 `python -m unittest discover -s backend/tests -p test_knowledge_chat.py`，覆盖主题排序、引用白名单、缺失依据、个人数据隔离和紧急分流。
