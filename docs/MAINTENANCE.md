# 维护规划

## 分工

项目负责人承担发布与许可决策；固件维护者负责协议、构建与硬件适配；服务/小程序维护者负责接口与回读；数据评估负责人负责授权、分组与独立评估。人员姓名由团队补充，不虚构已有人任职。

发布版本固定源码清单、依赖锁、验证命令、日志摘要与功能边界。主机检查通过不自动允许生产发布；影响物理输出的版本必须增加对应实机证据。

## 里程碑与退出条件

| 里程碑 | 退出条件 | 当前状态 |
|---|---|---|
| 可复现基线 | 脱敏仓库、许可证、依赖与电脑检查可复现 | 本地候选；公开仓库待发布 |
| 真实整机联调 | 手机 BLE、独立测试 Broker/MySQL、状态回读、停止操作实测 | 待样机证据 |
| 数据与算法评估 | 数据来源/授权/标签/分组、独立留出集、基线对照报告 | 未完成 |
| 输出与长稳验收 | 电流/温升/停止延迟、异常恢复、8 小时、OTA 中断回滚 | 未完成 |
| 自动提醒试验 | 上述验收齐全，明确适用边界与监督方式后另行批准 | 当前关闭 |

## 可持续性假设

开源基础工程供开发者复现；商业化方向可探索设备销售与家庭辅助服务。尚未形成经核实的销量、付费、ARR、制造成本或毛利数据，不在参赛材料中填入估计值作为业绩。合作与用户试验的承诺需要团队另行确认。
